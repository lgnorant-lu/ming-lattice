## 方法论正典（元模型先例）

- **Garrett, Elements of User Experience**（jjg.net/elements，2002）——五平面建造序 + 软件/信息二元性。UX 元模型祖师爷。
- **Hunicke/LeBlanc/Zubeck, MDA: A Formal Approach to Game Design**（GDC 2004, users.cs.northwestern.edu/~hunicke/MDA）——建造/体验双轴双向性的正式表述。学术论文。
- **Rebecca Ussai, The Principles of UX Choreography**（freecodecamp 2015, R/GA + Glen Keane）——Disney 12 原则→UX 五原则（feedback/feedforward/staging/focus/brand voice）。业界方法论。
- **Brad Frost, Atomic Design**（bradfrost.com + atomic-design repo）——部件层级心智模型；"非线性流程"的本人澄清 + token=亚原子。官方一手。
- **RampStack creative-direction framework**（rampstack.co）——四轴 brief 机读化 + drift 诊断。同位 skill 生态参照。
- **Storyflow, How to Run a Design Review**（storyflow.so, 2026）——direction/craft/decision 三型评审分离。社区方法文。
- **Jakob Nielsen, How to Run a UX Design Critique**（jakobnielsenphd.substack.com）——crit 结构化协议。权威从业者。
- **Structured Design Critique System**（claudecodehq.com/playbooks）——brief→评审计划→分区评审流水线。同位 playbook 生态。

## 同构方法论（外部印证）

- **The Spark: Engineering an Immersive, Story-First Web Experience** — Codrops 2026-01（Active Theory 系）。storyboard 先于引擎、叙事脊柱跨栈存活。官方一手 case study。
- **Inkwell — scroll-driven narrative** — Awwwards case（2025-05）。三幕弧 + 禁跳章单一旅程的结构选择。官方案例拆解。
- **playbook-scroll-experience** — github.com/Eneryleen/ai-web-design-codex。"2 句话说不清弧线即非叙事项目"、轻量栈分级、transform/opacity-only、reduced-motion 门禁。社区工程 playbook。
- **Storyframe 12-beat** — glidedesign.com。网站节拍框架（文案侧）。商业方法论，密度高但偏营销文案。
- **Famous Scrollytelling Examples: The Canon** — scrollytelling.ai。Snow Fall/Firestorm 正典梳理 + "snowfalling" 反噬史。社区综述。

- **M3 Motion tokens**（m3.material.io）+ **IBM Carbon motion** —— 官方设计系统规范。
- **UI/UX Atlas motion tokens 课** —— "choreography 留组件代码不进 token 层" 边界律。社区教程。

- **prefers-reduced-motion cascade** — css-animation.com accessible-motion-architecture。两层级联 fail-closed 结构 + decorative/essential/ambient 处置表。社区技术文。
- **Immersive 3D & Spatial UX 2026** — locallylost.com。WebGPU 阈值判据（CSS→Three.js→WebGPU）与空间可及性义务。社区指南。
- **The Architecture Behind Trionn** — Codrops 2026-07。GSAP+Three.js+Lenis+WebAudio 分工、`transitionReady`/`requestIdleCallback` 错峰、Web Audio 运行时合成。官方 case。

- **Three.js Camera controls** — svilenkovic.com。FOV 50-60 自然观感、near/far z-fighting 经验值。社区一手。
- **DeepSee Commerce case** — hontran.dev。性能预算保 WebGL 电影感的中端设备验收。开发者一手复盘。
- **ScrollStudio3D** — github.com/Wastetoken。keyframe 相机路径 + DOF/fog/bloom/FOV 的引擎化参照。开源工具。

- **Don Norman Emotional Design** / **Amber Case Calm Technology** / **Christopher Alexander Pattern Language** / **Tufte** / **Gestalt** / **Dan Saffer Microinteractions** —— 经典著作，按层引用。

## 明确不纳入

- **Awwwards/FWA 榜单站**——灵感入口不是规范源；截图式"获奖感"恰是克制门要防的；
- **Hero's Journey 直接套用**——12 段全用在产品页显套路；只取"角色位置演进"的内核；
- **通用设计系统教程**（Storybook/design-system 工程流）——那是 ui-design-paradigms 的域，本包只管"走到选型"的过程；
- **纯文案 story 框架全量**（Storyframe 12-beat 逐拍照抄）——节拍密度服务营销文案，产品系统体验用 5-7 阶段导演弧即可。
