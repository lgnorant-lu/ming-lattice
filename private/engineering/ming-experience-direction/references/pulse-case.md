## 关键决策摘编

| 决策点 | 选择 | 理由模式 |
|---|---|---|
| 主案竞选 | PULSE 胜（VEIL/PARALLAX 封存） | "最符合宪法与实例化基线"而非"最酷"——8 条契合点列举 |
| 世界模型 | Living System 非服务器列表 | 用户进入"关系与因果"而非物理设施 |
| 动效词表 | 六义：Balance/Deviation/Propagation/Branching/Constraint/Reformation/Evidence | 任何正式动态必须归入至少一义 |
| 场景压缩 | 10 beats → 6 chapters | 保留全部必要认知，不保留一一对应分页 |
| 英雄资产 | System Pulse Hero（丝带通道非霓虹节点网） | Product 与 Proof 共用同一对象世界 |
| 禁带清单 | 玻璃拟态/紫蓝渐变/霓虹/glitch/终端绿字/悬浮 HUD | 负面清单防风格串味 |
| 媒介配比 | 55-70% DOM / 15-25% SVG / 10-20% Canvas / 0-10% WebGL | 重媒介须证不可替代收益 |
| token 源 | MF-01 tamed 为身份锚 | 去色后一级关系靠明度/线宽/间距 |
| v0.1→v2.0 | 2D 线条 UI 拼盘 → WebGL Shader 体积场+3D Carrier | 升级仍逐层过 7 层栈 + 6 门重审 |

## 从实例萃取的判据

1. **宪法要演进**：v0.1→v0.3 三版显示宪法自身会随生态认知扩展——初版求全不如求准，后续版本扩面；
2. **v0.x 脉冲心态**：每层先出 Draft v0.1 立基线，修订走版本号（technical-mapping v0.2 因 HiC 调研修订）——设计文档也是活文档；
3. **蓝图可以返工**：18 spec 从 v0.1 的 2D 方案整体升级为 v2.0 WebGL 方案，门禁重审全过——方法允许推翻，不许绕过；
4. **工作笔记单独成文**：`02-narrative-working-notes` 是过程稿不进基线——思考痕迹与正式决策分离。

## 使用边界

PULSE 的产品身份、六义词表、7 阶段弧线是**该案实例**，不是方法本身——新项目应产出自己的词表与弧线。引用本案例只作"方法长这样"的参照，不作"方案抄这个"的模板。
