# Review Signal Audit — 信号位错审计协议

仓内每段规范性/描述性内容都坐在信任梯某一级上；**疾病 = 内容坐错层**。本协议审的不是新 diff（那是 review-core-paradigm 的域），是**静态信号面**——已在仓里安家的注释、TODO 族、抑制注释、文档祈使句、会话化石句，逐一判它们该不该留在现在这层。

思想来源：agent 把仓当训练语料，仓内任何 workaround+注释组合都会被当 de facto 模式病毒式复制；agent 写的"规则注释"还可能把一次性语境固化成伪永久规则（详见 `references/sources.md`）。对策不是禁注释，是**周期性把信号摆回正确的层**。

## 1. 何时用 / 何时不用

适用：

- 周期性仓面卫生审计——workaround 注释爬藤、TODO 陈债、抑制注释无声扩张；
- 怀疑散文规则该机械化（"这条禁止令为什么不是 lint 规则"）；
- 仓内"永久规则"疑似一次性语境化石（review 残句、会话裁决渗入文档）；
- 收割门禁提案——把散文约束晋升成机器不变量。

不适用：

- 单 diff/PR 的消融与独立评审 → `review-core-paradigm`；
- registry 与生成投影的漂移对账、依赖/导入边界 → 边界门与 `ming-boundary`（机械面已覆盖）；
- 单次会话流水账——本协议产出的是仓面清单，不是工作日志。

## 2. 信任梯与位错模型

```
L0 架构不可能   类型/目录约定/生成器契约——违例无法构造
L1 机器不变量   lint/hook 门/测试/schema/parity——违例即 fail
L2 声明契约     registry/boundaries/部署映射——声明即对账
L3 散文规则     SKILL 原则/AGENTS/治理文档/沉淀判据
L4 局部注释     inline comment、TODO 族、抑制注释
L5 瞬时语境     会话裁决、review 意见、一次性指令
```

原则：**内容应住在能机械执行的最低层；执行不了的才住散文层；瞬时语境永不固化。** 散文规则不是二等公民——它是尚无法机械化的知识的正确住所；病的是"本可机械化却留在散文"与"本不该留下却成了永久"。

## 3. 五病型 taxonomy

| 病型 | 定义 | 实例 | 处置方向 |
|---|---|---|---|
| **卡低位** | 规则表达在 L3/L4，本可在 L1/L0 | `// 禁止从此导入 vertical`（注释=未机械化约束） | 晋升→门禁提案 |
| **化石** | L5 瞬时语境写进 L3/L4 冒充永久规则 | `// 上次评审说别这么写`、文档里无出处的"永远" | 核出处→改写带界/删 |
| **僵尸** | 描述性内容的指涉物已变 | 过期注释、重构前语义的文档残段 | 删/改写 |
| **影规则** | 同一规则在两层表达且分叉 | 文档说一套、门查另一套；两包同题相反建议 | SoT 统一，败者删 |
| **复述** | 零信息内容 | `i++` 上写"递增计数" | 删 |

## 4. 统一协议

所有信号面共用同一四段协议；**扩展新面 = 加一行配方，不改协议**：

1. **sweep**——按配方机械扫描产候选集。可复跑、不求零误报（误报在 classify 段消化）；
2. **classify**——逐候选判病型。**判断归人不归正则**：同一 `// 暂时` 在测试夹具是判例说明、在生产码是辩护词；
3. **verdict**——四态处置：删 / 改写 / 保留带理由 / 晋升（§6）；
4. **harvest**——晋升提案格式化喂门禁 backlog。这是本协议的复利出口：审计不是清理活动，是**门的生产线**。

## 5. 信号面与扫描配方

| 信号面 | 配方 | 主治 | 本仓权重 |
|---|---|---|---|
| 代码注释节点 | 结构化语法搜匹配注释节点（排除字符串字面量内词） | 复述/化石/辩护词 | 低——代码面小 |
| 抑制注释 | 文本搜 `noqa\|disable\|ignore\|skip` 族 + 跨轮计数趋势 | 抑制面无声爬藤 | 中 |
| TODO/FIXME/HACK | 文本搜 + blame 取龄 | 陈债（长龄未动=化石嫌疑） | 中 |
| 文档祈使句 | 文本搜 `永远\|never\|always\|必须\|禁止\|不得` 扫规范与说明文档 | **每句问：机械化了吗**——没有=卡低位候选；有=该指引到门 | **高——散文面大** |
| 会话化石句 | 文本搜 `said\|上次\|当时\|临时决定` 扫仓内文档 | L5 渗入 L3/L4 | **高** |
| 跨包指导重叠 | 同主题多文档段语义比对 | 影规则 | 中 |

[警告] 词表只产候选集。命中≠违规，未命中≠清白——`classify` 段的语义判断不可省。

## 6. verdict 处置决策

- **复述** → 删；
- **辩护词**（解释为何不修根因的注释）→ 处置终点是**根因议题**不是删除——注释去留随根因修复走，[禁止] 只删注释留 workaround；
- **化石** → 核出处：查得着的改写带出处与时效界，查无实据的删；
- **卡低位** → 晋升提案进 §8 输出，本体暂留原位（提案落地后门接管，注释可删）；
- **影规则** → SoT 统一，败者删；分叉本身就是 finding；
- **保留** = 必须写保留理由。why 类注释（不可推导语义：规范条款、平台怪癖、安全不变量）是活口——本协议不反注释，反的是注释当创可贴与化石。

## 7. 晋升判据

某扫描面/模式被证明**确定性近零误报**时 → 提门禁提案（独立 warn/E 门）。仍是启发式的 → 留在本协议周期扫描。**噪声门比无门更糟**——误报训练人忽略警告面。

## 8. 输出契约

审计产出两份清单（可落 findings 文件或会话内直报）：

```
findings:        file:line | 病型 | 证据 | verdict | 保留理由(若留)
promotions:      规则内容 | 现居层 | 目标层 | 确定性评估 | 建议门/契约
```

跨轮纪律：已裁"保留带理由"的项记入 findings，下轮默认跳过防重议。

## 9. 禁令

1. **[禁止] 词表当判决**——sweep 只产候选，判型靠语义；
2. **[禁止] 删辩护词注释而留 workaround**——处置终点是根因议题；
3. **[禁止] 为审计新造工具**——文本搜/结构化语法搜/既有门足够；
4. **[禁止] 晋升未证确定性的模式**——见 §7；
5. **[禁止] 审计产出无人收割**——promotions 清单必须有去向（门禁 backlog/issue/沉淀条目），否则本轮审计零复利。

## 10. Compose

```
review-signal-audit（本包：静态信号面位错审计）
+ review-core-paradigm   （diff 评审：新落地改动的消融+独立 critic——它审增量，本包审存量）
+ depth-core-paradigm    （辩护词注释→根因议题的下潜深度裁决）
+ classify-core-paradigm （病型 taxonomy 演进/新增信号面的归域裁决）
+ ming-l-paradigm        （finding 处置去向的归域判定——晋升提案进哪个门）
+ ming-boundary          （边界类卡低位的机械化落点——boundaries.yaml 契约）
```
