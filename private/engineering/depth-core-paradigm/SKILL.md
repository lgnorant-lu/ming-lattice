# Depth Core Paradigm — 审计下潜深度裁决元规则

每个 finding/bug/事故都有一个隐藏问题：**它的因住在第几层**。两个对称失败都要防——浅读漏掉冰山（实例层补丁治不了结构层的因），过深挖浪费（在协议层找到因却在实例层修不了）。本包给下潜深度的裁决程序。

## 1. 偏差前提

- **浅读偏差**：启发性低的执行模型倾向把 finding 就地消化——症状层修掉即收工，冰山下的结构因被忽略；
- **过深偏差**：反过来对每个 finding 无限下挖——「为什么有宇宙」不是可行动的因；
- **静态规则已证伪**：5 Whys 类固定深度的失败档案——任意层数（大野耐一案例实为 7 层）、单路径假设（真实问题多因并置）、「最深=最优干预点」谬误、无客观停止判据（无限回归陷阱）。**深度不能按数字定，要按证据定**。

## 2. 层级地图（下潜经过哪几层）

对应冰山模型（Events→Patterns→Structures→Mental models）与 STAMP（约束失效只活在结构层）：

| 层 | 因的形态 | 信号 |
|---|---|---|
| **实例层** | 这个文件/这次输入的具体缺陷 | 单次、孤立、局部可复现 |
| **模式层** | 同类问题反复出现 | 复发、共因症状、同点补丁 churn |
| **结构层** | 架构边界/契约/数据流使错误必然 | 修了又犯、跨模块蔓延、契约被违反 |
| **协议/心智模型层** | 设计假设本身被证伪 | 「本该如此」的前提不成立 |

判别问题不是「挖多深」，而是「这个事件是**偶发**还是**系统的最新一次表达**」——后者必须下潜。

## 3. 程序（动态序贯下潜——主题）

1. **列层级假设**：因可能住在哪几层，各占多大先验；
2. **选区分度最大的探针**：最便宜、最能区分剩余层级假设的观察/实验（信息论测量选择——用最小探测砍最大诊断空间）；
3. **探→更新层级后验→重复**；
4. **停止判据（满足任一即停）**：
   - 当前层出现**可行动干预**：控制范围内 + 具体纠正动作 + 可验证预防；
   - 后验集中于单层；
   - 边际信息价值 < 探查成本（下一探的期望信息不值它的代价）；
   - 触达探查预算——按 §4 静态兜底收尾。

## 4. 静态回推（先验与绊线——不是固定层数）

- **类别默认深度**：碰契约/schema/协议/安全边界的 finding 默认多探一层；命名/格式/外观类默认浅层——先验按 finding 类别定，不按感觉定；
- **下潜信号清单（命中任一→假设空间向深层移动）**：复发模式 / 多症状疑似共因 / 同点补丁反复 churn / 设计假设被证伪 / blast radius 跨边界；
- **证据不足兜底**：后验不收敛时标「层级未定」入候审档，**不硬判**——层级未定本身是合法结论。

## 5. 禁令

1. **[禁止] 固定层数规则**：「总是问 N 次」已被证伪——深度按证据不按数字；
2. **[禁止] 最深=最优假设**：干预点按可行动性选，最深的因常需「深层改造+浅层止血」组合；
3. **[禁止] 单路径因果链**：多因并置须显式列出，不收敛成一条漂亮叙事；
4. **[禁止] 无证据深潜**：先验不足时回静态默认/候审档，不演绎式下挖；
5. **[警告] 浅层干预须记深层未排除**：选了浅层修复要写明「深层假设未排除」——给未来的复发留线索。

## 6. Compose

```
depth-core-paradigm（本包：finding 深度裁决）
+ review-core-paradigm（消融产 finding → 本包裁深度；评审流水线接力）
+ explore-core-paradigm（层级假设的空间拿不准时，先发散枚举可能层）
+ sec-core-paradigm（安全 finding 默认深层先验）
+ contract-core-paradigm（契约层 finding 的结构层锚点）
+ testing-core-oracle（探针的可验证化——区分度探针常是「写个测试看死活」）
```
